# 知疼统一请求协议

对齐微光知识库前后端约定。实现见 `src/common/request-envelope.ts`、`src/common/aes-transport.ts`。

## 方法

业务接口统一 `POST`。资源 ID、分页、筛选全部放在 body 的 `params` 中，不使用 URL query / path 参数。

例外：`GET /v1/health`、`/docs` 明文，便于探针与文档。

## 信封

```json
{
  "os": "ios",
  "version": "1.0.0",
  "language": "zh-CN",
  "params": {
    "user_id": "",
    "id": "可选资源 UUID",
    "...": "业务字段"
  }
}
```

- `params.user_id` 必填字符串；登录前 `""`。身份只认 Bearer Token。
- 开发默认明文 JSON。
- 生产强制 AES-128-CBC：请求明文为 `AAA##` + JSON；线上 body 为 `16字符 key + Base64`，`Content-Type: text/plain`。响应同样加密。
- 开发联调：`TRANSPORT_ENCRYPTION=true`（生产不可关闭）。

## 鉴权

```text
Authorization: Bearer <accessToken>
```
