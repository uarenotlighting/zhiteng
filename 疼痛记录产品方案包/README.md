# 疼痛记录产品方案包

本资料包汇总了前期对抖音、小红书公开内容的竞品调研，以及已经确定的产品形态、交互逻辑、版本顺序、数据模型和技术路线。

项目根目录另有两份直接约束界面设计与开发的品牌文档：

- `../01_品牌配色与暗色模式.md`：品牌色、明暗主题、状态色、疼痛色、人体图配色、无障碍与语义 Token。
- `../04_品牌定位气质与文案体系.md`：品牌定位、表达原则、标准界面文案与医疗边界。

## 已确定的产品路线

```text
微信小程序完整精简版
        ↓
抖音＋小红书小程序适配
        ↓（同时开发）
iOS＋Android 完整 App
        ↓
Apple Watch
```

三个小程序不是下载页或残缺试用版，而是可以独立长期使用的完整精简版。小程序首版只发布同源真实人体 2D；App 正式同时提供 2D＋3D，并通过高级趋势、批量报告、跨端同步、系统健康数据和 Watch 等自然增量吸引用户。小程序 3D 文档与资产路线继续保留，供后期版本开发。
