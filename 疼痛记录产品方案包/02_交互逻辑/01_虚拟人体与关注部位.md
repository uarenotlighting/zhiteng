# 虚拟人体与关注部位

## 核心思想

虚拟人体不是“身体部位选择器”，而是帮助用户寻找身体感受的外部载体。

```text
观察虚拟身体
    ↓
找到大概区域
    ↓
放大局部继续感受
    ↓
点选、涂抹或标记不确定范围
```

## 两层身体界面

### 全身模型

承担以下任务：

- 第一次选择关注部位。
- 临时记录其他部位。
- 查看本次多位置疼痛总览。
- 查看长期全身疼痛热力图。
- 管理关注部位。

### 关注部位

承担日常高频记录任务。例如用户只记录头痛，首页直接显示放大的头颈区域，不必每次从全身人体重新定位。

## 关注区域生成

用户可以选择一个或多个经常记录的部位：

- 头部
- 头部＋颈部
- 颈部＋肩膀＋上背
- 肩膀＋手臂
- 胸部＋上腹
- 腹部＋骨盆
- 腰部＋臀部
- 臀部＋大腿
- 膝盖＋小腿

初始化时选择关注部位不是必填项，用户可以跳过。关注部位数量不设业务上限。

关注区域由用户选择和组合。相邻部位可以组合为连续局部图；不相邻部位分别生成关注卡片。

系统可以根据历史记录提出组合或固定到首页的建议，但不得自动添加、组合或修改，必须由用户确认。

例如：

```text
用户选择：头部、颈部、右膝

首页生成：
1. 头部＋颈部
2. 右侧膝盖
```

用户可接受、拆分或重新组合系统建议。

关注卡片按照最近更新时间倒序排列，最近使用或编辑的卡片排在最前。

删除关注部位必须二次确认；删除后只移除快捷入口，不删除历史记录。

## 记录多个位置

多个位置属于同一个疼痛事件，但每个位置可以有自己的强度和感受：

```text
一次发作
├── 右侧太阳穴：7/10，跳痛
├── 右侧颈部：5/10，紧绷
└── 关系：从头部逐渐牵连到颈部
```

不相邻的位置不要强行缩在同一张手机画面中。记录时逐张卡片处理，保存后在全身总览同时显示。

## 位置表达方式

| 用户感受 | 表达方式 |
|---|---|
| 一个明确位置 | 实心点 |
| 大概在一片区域 | 半透明涂抹区域 |
| 身体深处 | 深色中心＋模糊光晕 |
| 皮肤表面 | 贴合轮廓的区域 |
| 说不清深度 | 虚线或半透明样式 |
| 疼痛扩散 | 渐变范围 |
| 牵连到其他位置 | 柔和连接路径 |
| 多次重复发生 | 热度叠加 |

## 不应限制用户

- 关注部位是快捷入口，不是可记录范围。
- 首页始终保留“记录其他部位”和“查看全身”。
- 删除关注部位不能删除历史记录。
- 用户连续记录同一区域后，可以建议固定到首页，但不自动修改。
