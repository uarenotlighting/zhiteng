# 核心数据模型

## PainEntry：一次疼痛事件

```text
PainEntry
  id
  accountId
  sourcePlatform
  status: ongoing/completed
  startedAt
  endedAt
  createdAt
  updatedAt
  locations[]
  timelineEvents[]
  suspectedTriggers[]
  accompanyingSymptoms[]
  medications[]
  reliefActions[]
  notes
  completionState
  syncVersion
```

## PainLocation：一个疼痛位置

```text
PainLocation
  id
  bodyPartId
  anatomicalStructureId: optional
  anatomicalSourceName: optional
  side: left/right/center/bilateral/unknown
  coordinateMode: 2d/3d
  view: front/back/left/right
  layer: surface/deep/muscle/bone/organ/unknown
  depthState: surface/internal_unknown/known/unknown
  geometryType: point/area
  normalizedX
  normalizedY
  modelX
  modelY
  modelZ
  radius
  maskData
  intensity0to10
  intensityLabel
  sensations[]
  certainty: exact/approximate/unknown
```

坐标与深度规则：

- `coordinateMode=2d` 时使用 `view + normalizedX/Y + bodyPartId`，`modelX/Y/Z` 必须为空。App 与小程序共用此格式。
- 2D 模式允许用户主观选择「皮肤 / 肌肉 / 骨骼 / 说不清楚」。肌肉与骨骼分别写入对应 `layer`，但均使用 `depthState=internal_unknown`，表示层次由用户自报、2D 模式并未产生精确深度或 3D 坐标。
- 只有在 App 3D 场景内完成表面命中或深度校准后，才允许写入 `modelX/Y/Z`，并将 `depthState` 设为 `surface` 或 `known`。
- `layer` 表示用户选择或已映射的解剖层，`depthState` 表示深度是否已确定，两者不得混用。
- 3D 表面点可额外保存射线下方命中的 Z-Anatomy / BodyParts3D `anatomicalStructureId`
  与原始 `anatomicalSourceName`；它们用于生成稳定的粗粒度部位文案，不表示诊断。

疼痛感觉规则：

- `sensations[]` 保存用户多选的主观感觉词，例如刺痛、跳痛、抽痛、灼热痛、电击样、压迫痛和放射痛。
- 2D 与 3D 使用同一份选项和存储字段；切换模型不清空已选感觉。
- 「说不清楚」与其他感觉互斥；这些词只表达用户主观感受，不表示病因或诊断。

## LocationRelation：位置关系

```text
LocationRelation
  fromLocationId
  toLocationId
  type: spread/referred/simultaneous
  notedAt
```

## TimelineEvent：发作过程变化

```text
TimelineEvent
  id
  painEntryId
  occurredAt
  type: start/intensity_change/location_change/medication/relief/end/note
  payload
```

## FocusArea：用户关注区域

```text
FocusArea
  id
  accountId
  name
  regionIds[]
  preferredSide
  preferredView
  zoomRect
  sortOrder
  createdBy: user/suggested
```

关注区域只是首页快捷入口。删除 `FocusArea` 不会删除 `PainEntry` 或 `PainLocation`。

## Medication 与 ReliefAction

```text
Medication
  id
  name
  dose
  unit
  takenAt
  effectDueAt
  effectCheckedAt
  effectResult: recovered/relieved/no_effect
  notes

ReliefAction
  type
  startedAt
  effectScore
  notes
```

用药规则：

- 药物名称允许自由输入，也可以复用历史药物。
- 同一个 `PainEntry` 可以包含多条 `Medication`。
- `effectDueAt` 默认为 `takenAt + 2 小时`。
- 效果三档分别为：`recovered`（完全好了）、`relieved`（减轻疼痛）、`no_effect`（无效）。
- 每次用药和效果确认都应保留为可追溯的时间线事件。

进行中事件应记录最近更新时间。连续 24 小时没有更新时只进入待确认状态，不自动写入结束时间。

## 模型版本

身体图和 3D 模型升级时，必须保存：

- `bodyModelVersion`
- `coordinateSystemVersion`
- `bodyPartTaxonomyVersion`

避免换模型后历史坐标漂移或区域含义改变。
