# 2D 正侧背视角缩放过渡 E2E

- 验收日期：2026-09-24
- 设备：iPhone 17（iOS 26.4 Simulator）
- 构建方式：`flutter run -d 51FB85A6-2374-4CD3-8215-C6EFFDCF4C7F --debug`

## 验收路径

1. 首页点击「记一次疼痛」，保持「2D 快速」。
2. 依次切换「正面 → 左侧 → 背面 → 右侧」。
3. 每次相邻视角切换时，确认人体使用从同一 3D 场景导出的 48 方位帧连续转向，不再直接跳到另一张正侧背图。
4. 确认转向使用与 3D `stepViewAnimation()` 相同的 340ms 和 `1-(1-t)^3` 曲线，并按相机弦线距离先接近放大、再回到原尺寸。
5. 确认痛点与人体一起转向和缩放，过渡结束后仍落在对应身体位置。
6. 确认舞台网格和顶部视角切换控件保持稳定，不跟随人体抖动。
7. 在过渡期间点击或拖动舞台，确认坐标逆变换仍对应当前动画尺度。
8. 将「头部」近景依次切换「正面 → 左侧 → 右侧 → 背面 → 正面」，录屏后按 5fps 抽帧检查动画中间帧。

## 结果

- 正面切换左侧时使用中间方位帧连续转向，同时呈现「靠近放大 → 回到原尺寸」，通过。
- 侧面图像、痛点与当前缩放框选对齐，通过。
- 网格未参与视角切换动画，无额外视觉跳动，通过。
- 48 张过渡帧均仅导出 `skin` 层，逐帧检查未再出现 3D 肌肉层，通过。
- 过渡帧统一在 768×1280 画布中居中渲染后缩小；正面帧透明区域中心 x=192，与 384px 画布中心一致，通过。
- 图片替换开启无缝播放，修正后录屏抽帧无空白帧，通过。
