# 2D / 3D 舞台网格透视缩放 E2E 验收

- 验收日期：2026-09-24
- 设备：iPhone 17（iOS 26.4 Simulator）
- 构建方式：`flutter run -d 51FB85A6-2374-4CD3-8215-C6EFFDCF4C7F --debug`

## 可重复路径

1. 首页点击「记一次疼痛」，保持「2D 快速」和「全身」。
2. 观察人体背后的网格，再点击「头部」。
3. 确认头颈肩放大时，网格格子也同比变大，网格线仍为清晰的 1 px。
4. 切换到「3D 精细」，选择「全身」，然后点击右下角「+」。
5. 确认 3D 人体靠近时网格格子同步变大。
6. 选择「头部」，确认摄像机聚焦头颈肩时网格再次按距离放大。
7. 点击「-」或「复位」，确认人体拉远时网格格子同步变小。

## 本次验收结果

- 2D：全身 → 头部时，人体与网格同步放大，通过。
- 3D：「+」放大时，人体与网格同步放大，通过。
- 3D：全身 → 头部聚焦时，网格呈现近大远小，通过。
- 网格始终以舞台中心为基准，不在缩放时产生漂移，通过。

## 尺度口径

- 全身默认视角为 1×，基准网格为 24 逻辑像素。
- 2D 按当前人体图缩放倍率调整网格。
- 3D 按「全身基准摄像机距离 / 当前摄像机距离」调整网格，并限定在 6–160 逻辑像素以避免极端视角闪烁或空白。
