# 知疼小程序前端

本项目是由 HBuilderX 管理的 UniApp Vue 3 项目，当前开发和验证目标为：

- 微信小程序。
- 抖音小程序。

小红书普通小程序仍保留在产品路线中，但当前阶段不开发；小红书“小组件”明确不在范围内。

## 在 HBuilderX 中运行

1. 用 HBuilderX 打开本项目目录。
2. 选择“运行 → 运行到小程序模拟器”。
3. 选择微信开发者工具或抖音开发者工具。

发行时使用 HBuilderX 的“发行”菜单。项目不使用 UniApp CLI，不需要执行 `npm install`、`npm run dev:*` 或 `npm run build:*`。

## 工程结构

- `pages/`：主包页面。
- `packages/locate/`：疼痛定位分包（真实 3D 人体 WebGL + 记录页）。
- `components/`：项目 UI 包装层和业务组件。
- `services/`：数据读写服务。
- `stores/`：应用状态。
- `styles/`：全局主题与语义化样式。
- `uni_modules/tdesign-uniapp/`：TDesign UniApp 组件库。

3D 人体模型已本地打包在 `packages/locate/static/models/human_body.glb`，详见 `packages/locate/ATTRIBUTION.md`。

## UI 与样式

- TDesign UniApp 通过 `uni_modules` 本地接入，无需 npm 依赖。
- 全局引入组件库已编译的 `theme.css`，项目不需要 Less 编译依赖。
- 项目自有样式可使用 UniApp 支持的 SCSS，颜色和主题以现有品牌文档为准。
- 人体地图和五档强度选择是知疼的业务组件，在项目内维护。

## 当前前端范围

- 首次引导。
- 游客访问限制和平台登录前端流程。
- 首页与关注部位快捷入口。
- 2D 正背面人体位置选择原型。
- 同页多位置记录。
- 五档固定强度选择。
- 刚开始、已经一会儿、已结束三种时间规则。
- 本地演示记录、历史列表和基础趋势展示。
- 浅色、暗色和跟随系统主题。
- 医疗边界与删除确认文案。
